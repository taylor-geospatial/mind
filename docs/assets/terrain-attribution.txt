Globe terrain

Elevation data: Mapzen Terrain Tiles, hosted by the AWS Open Data Registry.
https://registry.opendata.aws/terrain-tiles/
https://github.com/tilezen/joerd/blob/master/docs/attribution.md

globe-dem.png is derived from the 16 zoom-2 GeoTIFF tiles. Elevations were
resampled bilinearly from Web Mercator to a 2048 x 1024 equirectangular grid,
with pixel edges at longitude -180 to 180 and latitude 90 to -90 degrees.
Grayscale 0 to 255 encodes 0 to 9000 meters. Negative elevations and missing
polar coverage are zero. The globe uses exaggerated surface normals for
visual relief, fading the effect above 80 degrees latitude; it does not
displace the sphere or change the source PCA textures. Regenerate with:
uv run python scripts/data/build_globe_dem.py
